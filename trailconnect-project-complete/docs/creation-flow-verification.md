# Vérification du flux de création

La prévisualisation de TrailConnect a été contrôlée le 13 août 2026 sur le flux **Créer une sortie**. Les sections visibles couvrent désormais les informations essentielles, la trace GPX/KML, les métriques de parcours, l’aperçu météo de montagne à activer après ajout d’une date et d’une trace, puis les facilités au départ et sur le parcours.

Les facilités présentées comprennent les sanitaires, l’eau, le stationnement, l’accueil ou l’information, le réseau mobile, l’accessibilité, les notes libres et la date de vérification. Chaque statut offre les valeurs **Disponible**, **Limité**, **Indisponible** et **À confirmer**, afin d’éviter une promesse implicite de disponibilité.

L’aperçu météo de trajet est clairement présenté comme une donnée indicative qui requiert une trace GPX et une date. Le texte d’interface précise qu’il ne constitue pas une validation de sécurité ni d’accessibilité du parcours.

La vérification visuelle suivante confirme que chaque grand bloc dispose d’un repère iconographique : liste pour les essentiels, itinéraire pour le trajet et la météo, points reliés pour les facilités, groupe pour l’organisation et bouclier pour la visibilité ou la logistique. Ces icônes restent accompagnées d’un titre textuel pour préserver l’accessibilité et la compréhension sur mobile.

Le bloc **Image de couverture** est visible dans les essentiels, juste après la description. Il accepte une image JPG, PNG ou WebP, prépare une version compressée dans le navigateur, affiche une prévisualisation avant publication et permet de retirer l’image avant l’envoi.
