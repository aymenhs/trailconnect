# Alertes météo participantes

Les alertes présentes dans la fiche de sortie sont des **repères indicatifs** dérivés de l’aperçu journalier Open-Meteo de la zone de départ. Elles améliorent la visibilité des conditions prévues, sans déterminer si une sortie est praticable, sûre ou maintenue.

| Condition retournée par l’aperçu | Seuil d’affichage | Libellé participant |
| --- | ---: | --- |
| Code météo orageux | `≥ 95` | Orage possible |
| Rafales maximales | `≥ 50 km/h` | Rafales élevées prévues |
| Probabilité maximale de précipitations | `≥ 70 %` | Précipitations probables |
| Température minimale | `≤ 0 °C` | Températures froides prévues |

Chaque fiche conserve la source, les valeurs détaillées et un rappel explicite : les données concernent la zone de départ, elles ne constituent pas une alerte officielle ni une évaluation de sécurité, et les participants doivent consulter les sources locales officielles et adapter leur décision aux conditions sur le terrain.
